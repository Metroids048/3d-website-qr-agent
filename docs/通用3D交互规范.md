# 官网首屏 3D 自主表演规范

- 官网首屏。结合官网位置与参考图选可辨认的立体主体、取景、主光与前后景。吉祥物、企业形象、Logo、产品分别提取轮廓、材质或部件特征。成品以真实组件嵌入完整本地网页。
- 自动循环。组件进入视口即播放，无需点、拖、转或移动光标。主体动作有开场、展开、回落和无跳变复位。镜头、光线、背景和前景基于同一节拍变化。生态、工业和角色各有构图和编排。鼠标或单指可拖动整个画面旋转，拖动期间保留动画节拍，松开后从所选视角继续。悬停用抓手提示。键盘用方向键旋转，保留暂停和减少动态效果。场景中不放加号、拖拽点、跟随光标的效果、交互信标或点击热点。
- 轮廓型首屏。独立 Logo、网页图标和需要保留原画整体的透明插图默认转侧露出连体侧壁。厚度随轮廓的局部宽窄变化，首秒见厚度，随后两段贴合并缓停。保留正面图案、留孔和比例。要求部件独立活动的完整角色以及明确匹配的产品场景沿用相应表现。
- 双击归码。原生双击事件从最后一帧的时间和位置开始粒子重组，不等下一次循环，不等单击计时或网络。拖到侧面或背面后仍从最后一帧收拢。粒子聚成彩色艺术码。再次双击，粒子反向重组并恢复触发时的画面姿态。触屏可双点或用展开按钮。
- 彩色艺术码。使用素材的色系与图形记忆点，把图案纳入码面。保持正确载荷、定位结构和留白，先验同版导出文件，再验实际网页最终画面。原码分开保存，公众号原码保留原文件字节。
- 交付。官网预览 site.html、独立嵌入组件 component.zip、彩色艺术码 art-qr.png、备用原码、接入说明 README.md。关闭脚本可用备用码。原码、艺术码及浏览器终态分别验证。真机和上线情况如实记录。
