# 3D 二维码交付规范 · 拖拽旋转对齐

2026-11-23 经用户确认，适用于这个项目后续所有新制作。Logo、企业形象、吉祥物和其他主体共用同一套成码要求。品牌造型、色彩、材质和应用场景随输入变化。

## 最终交付长什么样

- **一件从二维码格子上长出来的立体作品。** 先用原码或确切链接确定码格，把格子的高低、表面、侧壁和留白做进立体结构。斜看能看出纵深、层次和该素材的辨识特征，参与成码的几何也要承担造型。标志可以用轮廓和关键折面，角色可以用辨识度高的部件。观众需要看得出这件作品对应的是给定素材。
- **观众亲手转到 90°。** 鼠标或触摸按住拖拽，在斜视和正俯视之间连续控制观察角度，途中随时可停、可回拖。可以环看和挪动视图，辅助视角控件与拖拽共用观察状态。90° 指视线垂直于本件作品的码格基面。回拖后能看见同一批构件原来的高差和侧面。
- **到 90° 时，码来自同一件物体的投影。** 成码过程中，构件的位置、实际高度、形状和用于识别码格的明暗配色保持固定。由旋转产生遮挡变化和侧壁缩短，正俯视时立体表面与留白对齐成完整网格。截取成品此刻真实画面即可解码成给定载荷。原码的用途、目标与载荷继续保留，扫码位须有清晰的定位结构、格子对比和净空。

交付物以可直接操作的 3D 预览为主。随件给出实际输入、斜视／中途／90° 浏览器画面、扫码去向和对应检查结果。官网交付时同时将同版交互放进网页预览及可嵌入组件，在解压后的交付包里验证。普通二维码可以用于同去向对照或备用，单独标明用途。

## 怎么验收同一份成品

| 核什么 | 看哪个结果 |
| --- | --- |
| 原始输入和立体效果 | 对照实际素材和成品斜视，核主体关键特征、前后层次、可见的立体延展。记录原码或确切去向，说明观众在哪看到它、扫完拿到什么。 |
| 旋转连续且结构一致 | 在真的交付页面从斜视小步拖过多个中间角，临近 90° 时慢拖并回拖。核对角度随输入连续变化、构件没有重排或消失、停住时姿态稳定。截取实际浏览器分帧。可用构件坐标、尺寸和材质状态与相机角度一起留证。 |
| 90° 原生画面读码 | 从拖拽所到的 90° 帧截取 3D 画布，使用两种解码器回读并比对预期载荷。按实际交付尺寸检查对比和净空。记录近端视角的实测范围，扫码能力以确认的角度和设备为准。 |
| 落到真实出件 | 对正式 Agent 候选，用实际接单入口提交对应输入，再验证本次回执打开的网页、下载组件和扫码画面。手机相机、微信扫一扫、客户页面或物理展品如在使用范围内，分别以实际条件留证。 |

**已知反例。** 双击让 3D Logo 散开后另显平面码、摆件旁加码牌、旋转末段压低造型并切换成黑白、用截图或单独导出的静态码通过读码检查，都缺失本产品要求的连续旋转成码。只要拖动过程出现这类情况，就按未通过处理，即使 90° 画面能识别。

可复用的实现是把有码格的实体布置在固定网格上，以正交镜头角度控制视图。斜看时有可见的侧壁，到了 90°，各高度上的顶面仍对着自己的格位。方柱、山脊和三色材质是已经验收的样件实现，后续按素材设计空间形态。优先验证一组有代表性的原始输入和连续拖拽，再做场景扩展。
